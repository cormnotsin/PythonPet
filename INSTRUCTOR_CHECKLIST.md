# ✅ Pre-Class Checklist - Choose Your Path

## 🔍 First: Determine Your Setup (2 weeks before)

### Test School Computers:

- [ ] Can you install software on school computers?
  - **YES** → Use **Plan A** (Python + VS Code) ✅ Best option!
  - **NO** → Continue to next question...

- [ ] Can you access python.org in school browsers?
  - **YES** → Use **Plan B - Python.org Shell** ✅ Excellent backup!
  - **NO** → Continue to next question...

- [ ] Can you access colab.research.google.com?
  - **YES** → Use **Plan B - Google Colab** ✅ Good alternative!
  - **NO** → Continue to next question...

- [ ] Do you have internet access at all?
  - **YES** → Use **Plan B - Demo only** (teacher projection)
  - **NO** → Use **Plan B - Offline activities** (last resort)

---

## 📋 Plan A Checklist (Python + VS Code - IDEAL)

### 2 Weeks Before:
- [ ] Verify Python 3.x is installed on school computers
- [ ] Verify VS Code is installed on school computers
- [ ] Test running a simple Python program
- [ ] Print student materials (STUDENT_DEFINITIONS.md, QUICK_REFERENCE.md)

### 1 Week Before:
- [ ] Copy project folder to school computers or USB drive
- [ ] Test all three programs (my_pet.py, pet_game.py, coding_celebration.py)
- [ ] Verify tasks.json works (Run Task commands)
- [ ] Prepare projector/screen for demonstrations

### 3 Days Before:
- [ ] Read TEACHER_GUIDE.md thoroughly
- [ ] Review daily lesson plans
- [ ] Print 2-3 extra copies of all student materials
- [ ] Prepare error troubleshooting examples

### Day Before:
- [ ] Test one school computer completely
- [ ] Have all materials printed and organized
- [ ] USB backup ready with all files
- [ ] Student materials ready to distribute

### Day Of:
- [ ] Arrive 15 minutes early
- [ ] Test one computer in lab
- [ ] Have project folder open on teacher computer
- [ ] Student materials on desks or ready to hand out
- [ ] Projection ready for demonstrations

## 🎉 Success Indicators Checklist

### You're Ready to Teach When:

- [ ] You've chosen Plan A or Plan B
- [ ] You've tested your chosen platform
- [ ] Student materials are printed
- [ ] You've read the lesson plans
- [ ] You have backup options ready
- [ ] You're familiar with common errors
- [ ] You can demonstrate the basics
- [ ] You're excited to teach coding!

### During Class, Success Looks Like:

- [ ] All students can access code environment
- [ ] Students can run code and see output
- [ ] Students can make changes to code
- [ ] Students can run code again to see changes
- [ ] Students are engaged and curious
- [ ] Questions are answered (by you or materials)
- [ ] Students customize their pets
- [ ] Students are proud of their work
